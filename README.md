# medical-literature-ai-pipeline
医学文献自动采集与AI内容生成系统
# 医学文献AI自动化流水线
> 大一软件专业 | 医学爬虫 | AI内容生成 | 自动化同步

## 项目简介
一套全自动的医学文献采集与内容生产系统，可自动爬取 Google Scholar、PubMed 等平台的最新文献，生成科研简报、公众号/小红书科普文，并自动同步至 Google Docs/Tasks。

## 核心功能
1.  **文献检索与推送**
   - 爬取肺癌、肺移植、胸交感神经切除等方向的最新文献
   - 支持时间范围、Top期刊筛选
   - 自动提取题目、作者、摘要、核心数据
2.  **科研简报自动化**
   - 每日生成 ≥2500 字深度简报
   - 包含统计学分析、亚组分析、指南解读、专家思考模块
3.  **科普内容创作**
   - 自动生成公众号版（>3000字）和小红书版（800-1000字）科普文
  


## 技术栈
- **爬虫**：Python + Selenium/BeautifulSoup + Requests
- **数据处理**：Pandas + 结构化解析
- **AI生成**：大模型API（GPT-4o）+ Prompt工程
- **自动化**：APScheduler + Google API

## 项目亮点
- 完整实现企业级内容生产流水线，可直接迁移至直播/电竞/短视频领域
- 大一阶段独立完成，具备扎实的工程实现与问题解决能力
- 代码可直接运行，文档完善，可快速部署

## 运行方式
1.  安装依赖：`pip install -r requirements.txt`
2.  配置 API Key 与定时任务
